# Inception Stack

Dockerized WordPress stack with Nginx (SSL termination), PHP-FPM WordPress, and MariaDB. Uses host bind mounts for data durability under `/home/casper/data`.

## Stack
- Nginx: HTTPS reverse proxy, serves WordPress, uses self-signed cert in `srcs/requirements/nginx/tools`.
- WordPress: PHP-FPM 7.4 + WP-CLI install on container start via `tools/setup.sh`.
- MariaDB: Initializes database/user from env vars.

## Prerequisites
- Docker and docker-compose available on PATH.
- Host directories created for bind mounts:
  ```sh
  mkdir -p /home/casper/data/mariadb_data /home/casper/data/wordpress_data
  ```

## Configuration
- Copy `srcs/.env.example` to `srcs/.env` and fill secrets (file is gitignored and stays local).
- Environment file: `srcs/.env` (DB creds, admin user/email, site URL, etc.). Adjust before building.
- Compose file: `srcs/docker-compose.yml` defines services, bind mounts, and the `inception` network.
- TLS: self-signed cert/key already included for local HTTPS.

## Usage
- Build & start in background: `make all`
- Stop containers: `make down`
- Stop + remove volumes + prune Docker: `make clean`
- Rebuild from scratch: `make re`

## Useful commands
- Tail logs: `docker-compose -f srcs/docker-compose.yml logs -f`
- DB shell: `docker exec -it mariadb mysql -u root -p` (root password from `srcs/.env`).
- WP CLI inside container: `docker exec -it wordpress wp --path=/var/www/html <cmd>`
